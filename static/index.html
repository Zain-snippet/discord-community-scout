Getting started

  1. Add a community you already know, by hand.
  2. Or import a CSV of listings and review the preview before saving.
  3. Score and review each community, then draft a message tailored to it.

Discovery through public directories is limited to sources whose terms actually permit automated access. See docs/data-sources.md for the audit.
